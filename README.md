# Battery health pitch deck

An animated, picture-led pitch deck for the charge-only battery health prototype
([battery-analytics-prototype](https://github.com/qwertykeypadapple/battery-analytics-prototype)).

Slides scroll horizontally. Use the ‹ › buttons, the arrow keys, or the dots at the bottom.

## View locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/index.html.

## Notes

- All figures come from the prototype's own reports (lab datasets only; no Baaz data yet).
- Battery shapes: NASA 18650 from the repo inventory; Oxford pouch from the authors' paper; CALCE CX2 prismatic from general knowledge, to confirm.
